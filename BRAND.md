# Alessandro Bruno — Brand Guidelines

This document defines the visual identity, logo system, color usage, typography, spacing, and implementation rules for the **Alessandro Bruno** personal brand.

The identity is built around the custom **`ab.` monogram**: a sculptural lowercase `a` and `b` combined into a continuous ribbon-like form, followed by a distinctive dot. The primary visual language combines **metallic silver**, **charcoal black**, **pure white**, and **electric blue**.

The goal of the system is to feel:

- Professional
- Technical
- Modern
- Premium
- Minimal
- Recognizable at small and large sizes
- Suitable for software engineering, open source, product work, and personal branding

# 2. Core Logo Concept

The `ab.` symbol is the main identifying element of the Alessandro Bruno brand.

The mark consists of:

1. A stylized lowercase **`a`**
2. A flowing central ribbon that transitions into the **`b`**
3. A tall vertical stem that creates the visual anchor
4. A rounded right-side bowl
5. A separate circular **dot**
6. Metallic or monochrome treatments depending on context

The logo should always remain recognizable as a single visual unit.

The shape must not be stretched, compressed, rotated, skewed, redrawn, or reconstructed with a standard typeface.

**File:** `ab-monogram-metallic.svg`

## Purpose

This is the primary and most expressive version of the brand mark.

It should be used when the brand itself is a major visual element, such as:

- Homepage hero sections
- Portfolio landing pages
- Personal website navigation
- Social media profile graphics
- GitHub profile banners
- Personal presentations
- Brand documentation
- High-resolution marketing material
- Splash screens
- Featured project graphics

## Appearance

The logo uses a premium metallic treatment with gradients moving between:

- Bright silver
- Cool white
- Steel gray
- Soft blue-gray
- Dark metallic shadow

The dot uses an electric blue treatment.

## Recommended Backgrounds

Best:

- Charcoal
- Near-black
- Deep navy
- Very light neutral gray
- White, if contrast remains sufficient

Preferred dark background:

```text
#0B0D10
```

Alternative dark background:

```text
#101318
```

## Minimum Size

For digital use:

```text
Recommended minimum width: 48 px
Preferred minimum width: 64 px
```

For high-fidelity metallic reproduction:

```text
Preferred width: 96 px or larger
```

The metallic treatment should not be used at extremely small sizes where the gradient details become unreadable.

## Clear Space

Maintain clear space around the logo equal to at least:

```text
0.25 × logo height
```

For hero or presentation use:

```text
0.35 × logo height
```

# 4. Primary Full Logo — Metallic

**File:** `ab-logo-metallic-full.svg`

## Purpose

This is the formal version of the Alessandro Bruno identity.

It combines:

- The metallic `ab.` monogram
- The `ALESSANDRO BRUNO` wordmark

Use it when the viewer may not already know the brand.

Recommended applications:

- Portfolio homepage
- Brand page
- CV cover
- Case study cover
- PDF documents
- Presentation title pages
- Press or media assets
- Professional profile graphics
- Website footer
- About page

## Wordmark

The full name should appear as:

```text
ALESSANDRO BRUNO
```

Always uppercase.

Recommended visual characteristics:

```text
Font weight: Light / 300
Letter spacing: 0.35em–0.45em
Alignment: Centered
Case: Uppercase
```

The wordmark should remain secondary to the monogram.

## Spacing Between Mark and Wordmark

Recommended vertical space:

```text
0.15–0.22 × monogram height
```

The wordmark should never touch the monogram.

# 11. Typography

The monogram itself is a custom graphic and should never be recreated with a normal font.

The `ALESSANDRO BRUNO` wordmark is visually closest to a lightweight geometric sans-serif with wide tracking.

## Recommended Wordmark Font

### Preferred

```text
Manrope Light
Weight: 300
```

Recommended styling:

```css
font-family: "Manrope", sans-serif;
font-weight: 300;
text-transform: uppercase;
letter-spacing: 0.40em;
```

### Alternative

```text
Inter Light
Weight: 300
```

Recommended styling:

```css
font-family: "Inter", sans-serif;
font-weight: 300;
text-transform: uppercase;
letter-spacing: 0.38em;
```

## Website UI

Recommended primary interface font:

```text
Inter
```

Suggested weights:

```text
300 — Light
400 — Regular
500 — Medium
600 — SemiBold
```

## Display / Hero Typography

Recommended:

```text

Manrope
Geist
```

Suggested hero settings:

```css

letter-spacing: -0.03em;
```

# 25. Incorrect Usage

Never:

- Stretch the logo horizontally
- Stretch the logo vertically
- Rotate the logo
- Add outlines
- Add random strokes
- Add drop shadows to monochrome variants
- Replace the blue dot with an unrelated color
- Recreate the monogram using text characters
- Change the relative size of the dot
- Move the dot closer or farther without a layout reason
- Crop the logo tightly
- Place the logo over visually noisy backgrounds
- Use low-resolution screenshots instead of official assets
- Add bevels to the monochrome variants
- Apply rainbow gradients
- Separate the `a` and `b`
- Add effects that make the logo difficult to recognize

---

# 26. Dot Rules

The dot is a signature element.

In the metallic version:

```text
Electric blue
```

In monochrome versions:

```text
Same color as the monogram
```

Do not:

- Remove the dot from the official `ab.` mark
- Replace it with another symbol
- Use multiple dots
- Turn it into a square
- Change its relative scale significantly

The dot can occasionally be used by itself as a tiny decorative brand accent in UI, but it should not replace the main logo.

---

# 27. Motion Guidelines

If the logo is animated, motion should remain restrained.

Recommended animations:

- Gentle metallic light sweep
- Dot fade-in
- Dot pulse
- Subtle ribbon reveal
- Mask-based logo reveal
- Slow parallax
- Small hover reflection

Avoid:

- Bouncing
- Cartoon motion
- Excessive rotation
- Fast flashing
- Strong glow pulses

Suggested duration:

```text
400–900 ms
```

Hero reveal:

```text
800–1400 ms
```



# 34. Brand Tone

The visual identity should communicate:

**Precision**

The design should feel deliberate rather than decorative.

**Engineering**

The system should look structured, technical, and functional.

**Craft**

The metallic treatment adds a sense of care and depth.

**Forward motion**

The flowing ribbon structure suggests movement and evolution.

**Individuality**

The monogram should be recognizable independently from the full name.

---

# 35. Final Brand Principle

The identity should always feel like a **software engineer's personal brand**, not a generic agency logo.

Prefer:

- Strong typography
- Clean layout
- Functional interface design
- Thoughtful motion
- Dark technical surfaces
- Minimal blue accents
- Large areas of negative space
- Strong project storytelling

Avoid unnecessary decoration.

The `ab.` mark should remain the most distinctive visual element of the Alessandro Bruno identity.
