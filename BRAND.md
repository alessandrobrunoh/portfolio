# Alessandro Bruno — Soft-Minimal Brand Guidelines

## Overview

This document defines the **soft-minimal** brand system for **Alessandro Bruno**.

The identity is centered on a custom **`ab.` monogram**:
- lowercase `a`
- lowercase `b`
- a distinctive blue dot
- soft pale gray-blue surfaces
- subtle gradient transitions
- flat 2D appearance with depth suggested only through tone, not 3D material

This direction should feel:

- minimal
- calm
- premium
- modern
- quiet
- technical
- precise
- friendly but not playful
- professional enough for engineering and product work

The visual tone should sit closer to:
- Apple-like minimal restraint
- Google-like clarity and usability
- modern product design systems
- soft editorial whitespace
- understated UI with strong hierarchy

---

## Brand Intent

The brand should communicate:

- **Systems thinking**
- **Engineering precision**
- **Product clarity**
- **Calm confidence**
- **Modern craftsmanship**

The identity must not feel:
- loud
- ornamental
- gaming-heavy
- metallic
- overly glossy
- aggressive
- futuristic in a sci-fi way

## Gradient Guidance

The soft-minimal logo should use **very restrained gradients**.

Allowed:
- subtle left-to-right tonal shifts
- pale blue-gray blending
- transparent-feeling overlap transitions
- gentle edge contrast

Avoid:
- metallic reflections
- chrome
- hard specular highlights
- 3D extrusion
- glassmorphism blur inside the logo
- noisy textures

Gradient mood:
- soft
- clean
- barely there
- premium but calm

---

## Logo Geometry and Visual Language

The logo should read as a custom sculpted 2D mark made of large geometric forms:
- soft rounded bowl for `a`
- upper cap for `a`
- central descending shape connecting the forms
- tall vertical stem
- wide rounded `b` bowl
- isolated dot accent

The whole mark should feel:
- balanced
- centered
- stable
- calm
- custom
- easy to recognize at a glance

---

## Clear Space

Use the blue dot diameter as the spacing unit.

Let:
- `x = diameter of the dot`

Minimum clear space around the logo:
- `1x` on all sides

Preferred clear space:
- `1.5x`

Hero / presentation use:
- `2x`

No text or UI element should crowd the logo.

---

## Minimum Sizes

### Monogram
- absolute minimum: `16 px`
- recommended for UI: `24 px`
- recommended for standard web usage: `32 px`
- ideal for hero / visible brand usage: `64 px+`

### Full Logo
- absolute minimum width: `120 px`
- recommended width: `180 px+`
- hero / presentation width: `280 px+`

### Wordmark
- minimum width: `140 px`
- recommended width: `220 px+`

---

## Background Rules

### Preferred Backgrounds
- `#FFFFFF`
- very light neutral gray
- soft off-white
- pale cool gray
- deep charcoal (for white version only)

### Avoid
- highly saturated backgrounds
- detailed photography behind the logo
- busy gradients
- textured surfaces
- strong patterns

The soft-minimal primary mark performs best on spacious, quiet surfaces.

---

## Typography

### Primary UI Typeface
Use:
- **Inter**

Recommended weights:
- 300 — Light
- 400 — Regular
- 500 — Medium
- 600 — SemiBold

### Alternative UI Typeface
Use if desired:
- **Manrope**

### Wordmark Style
For `ALESSANDRO BRUNO`:
- uppercase
- very wide tracking
- clean sans-serif
- light weight

Recommended CSS:
```css
font-family: "Inter", sans-serif;
font-weight: 300;
text-transform: uppercase;
letter-spacing: 0.35em;
```

## Accessibility

On light backgrounds:
- use black text or black monochrome logo when necessary for contrast

On dark backgrounds:
- use white logo variants

The pale soft-minimal logo should not be used if it becomes too low-contrast against the chosen surface.

Always provide:
```html
alt="Alessandro Bruno"
```

---

## Incorrect Usage

Never:
- add metallic reflections
- add hard black outlines
- rotate the logo
- stretch the logo
- recolor the blue dot to arbitrary colors
- add shadows stronger than the brand style allows
- place the logo on busy imagery
- put the soft logo on low-contrast backgrounds where it disappears
- modify the relative proportions of the monogram
- replace the wordmark with another font style that feels decorative
